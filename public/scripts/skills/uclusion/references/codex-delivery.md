# Codex native Poke delivery

Recipient changes require a turn in the intended conversation, including after /new. Inspect read-only with `uclusion codex-recipients`, never send input. Receipt proves no processing or command cancellation. Startup supplies no retained history; never add --deliver-existing-pokes yourself. Human-requested replay is a private unmarked copy handled only as requested. Delivery is not guaranteed before first turn or across deliberate quit/restart; never narrate default startup/skipped history.
