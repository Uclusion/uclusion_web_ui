# Adopt and subscribe

Read [claims.md](claims.md) completely.

Subscribe when adopting a job or standalone bug, whether a human selected it or it was adopted automatically. Before the native Codex subscription call, discover the exact `set_agent_subscription` definition and schema if not held. Pass the selected work's short code; the native proxy supplies identity, so do not invent or pass an agent ID. Claude Code and Cursor use the subscribe command in their selected delivery reference. Retain the returned canonical work and agent identity with the assignment. Report a failed subscription as unfinished adoption and retry before dependent work. Subscribing on adoption keeps later updates for that work reaching this conversation. Subscriptions are permanent: nothing releases them.

Keep adoption and subscription outcomes separately for each canonical job or bug; adopting work for another helper does not replace existing assignments or receipts. On a confirmed bug-to-job move, subscribe to the returned job before continuing and update only that work's assignment mapping; the former bug keeps its subscription. Record reads and helper research do not subscribe.

For recovery, retain the selected work, canonical identity and confirmed or unfinished subscription outcome. Reconcile only missing or changed facts and finish the subscription before dependent work.
