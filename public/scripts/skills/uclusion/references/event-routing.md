# Lane routing

While idle, honor live `Start <target>` by starting/resuming that target. While assigned, accept only known lane members; compound membership follows the parent after `of`. Defer unknown/unrelated targets without lookup. Bare Start remains an event even in chat; only explicit human switch language changes a retained lane. Multiple idle default agents need human selection in one chat, not inbox election.

Forward known view-note updates through helper-dispatch.md's reference/version handoff without body preloading. For other accepted direct codes requiring lookup, use exact-code `get_job`; retry newly Added direct 404s later. For compound events, load an unseen parent with `initial_read:true`; with a held parent, read only the poked `thread_only` item. Qualify nested local codes as `<question>_<local>`; never globally look up a bare local code.
