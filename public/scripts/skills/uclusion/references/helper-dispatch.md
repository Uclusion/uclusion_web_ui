# Helper dispatch

Use fresh helpers without inherited history (`fork_turns: "none"`) for all nonretained coordinator work. No available/permitted fresh helper means report why, never coordinator fallback. Source/log/diff investigation, reproduction/measurement and code review use investigation helpers; implementation/tasks/bugs/permitted deployment use implementation helpers; design uses its selected sibling package. Tests/builds require the investigation/implementation brief's independently approved actions. Helpers receive no coordinator bodies/history/bootstrap.

Compile freeform bounded question/fix, repository/evidence paths and permitted/withheld actions under standing-instructions.md. Retain useful returned findings and refresh the variable brief from qualified decisions.

## Investigation and code-review helpers

Pass the selected absolute [investigation-helper.md](investigation-helper.md) path plus one bounded question and exact permitted reproduction/measurement/tests/builds; require its complete read before action. Code review is that bounded question. Never read/copy its stable body for dispatch.

## Implementation helpers

Pass selected absolute [implementation-helper.md](implementation-helper.md), target/job/owner/current R-code/actual version, constraints/evidence/independent permissions and only that exact thread-read grant. The helper reads/validates the complete capsule, not a reconstructed brief; no coordinator body fetch solely for dispatch. Job/independent/grouped ownership follows job-context.md. Standalone bugs instead receive the complete agreed fix/evidence/verification. Require role read before edits, exclude coordinator bootstrap from repository constraints and include product names only when source work needs them. No copied protocol, parser or grant/state architecture.
