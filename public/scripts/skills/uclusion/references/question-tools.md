# Questions, options and suggestions

File every known distinct question, option and required vote in the current turn with the role's permitted tool. The performer checks its own action authority and returns the original question and exact unresolved evidence to `design`. Unsettled assistance blocks dependent work and approval; independent authorized work continues. Record a proposed improvement with `make_suggestion` when that write is permitted; otherwise return a bounded suggestion request to `design`.

Unknown facts, reproduction, observed behavior and meaning need open questions without options; real discrete choices may have options. Source inspection does not establish unobserved runtime behavior.

A question with options, and each `add_options` call, carries your one explained For vote. Human attribution of a record or vote requires the human's supplied words, certainty and reasoning. Retain the question-creation receipt's link, qualified option codes/names, initial vote and resulting stage. Name new evidence or requirements for any preference change, including when adding options; later vote changes use `approve_job_or_option`. Give a new choice its own identity. Visuals show the exact canonical option codes/names and stay synchronized with the options in the same turn.

## Answers to job questions

A clear human reply or Approvable For vote answers a job question when it is non-AI and non-advisory. Advisory input may inform reasoning or votes; execution still needs qualifying authority. Human Resolve delegates the choice and leaves versioned AI handling pending.

## Existing standalone questions

The permitted tools are `get_job`, `add_info` and `approve_job_or_option`. A clear non-AI reply or non-AI Approvable For vote answers; no job advisory gate applies. When every answering vote has rendered certainty at most 50/100:

- If a better option is available, report that creating it requires `add_options`, outside this permitted set.
- Otherwise add certainty-improving information if available, or proceed.
