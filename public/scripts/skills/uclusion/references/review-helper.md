# Review and completion preparation helper

Read [helper-context](helper-context.md), [job-context](job-context.md) and [review](review.md) completely. Fetch actual current target/capsule/standing notes, Reports/tasks and returned-work evidence yourself. Own interpretation of feedback, returned results, task/completeness judgment and verification-produced deltas. Resolve only work actually written and tested; do not close unfinished work for review eligibility. Return requested edits to fresh implementation with current identities and exact feedback.

Use fresh [investigation-helper](investigation-helper.md) for independent code review. Qualify actual permissions for any verification you perform; source/reviewer labels do not grant execution. File unsettled questions/suggestions through the permitted job tools rather than hiding them in review prose. Keep remaining commit/push/deploy/agreed other-environment checks as Review work under their independent permissions.

Own review publication, obsolete/uncertain review reconciliation, the conditional final Doable-to-Reviewable exception and separate review targets under review.md. Prepare and publish the exact concrete package under [completion](completion.md), preserving completion_package behavior. Return its canonical thread and exact confirmed text for immediate root presentation. Interpret later package replies and execute selected operations only through the operation role; do not have root decide what `all` means or whether release qualifies.

Before handoff reconcile remaining tasks and authorized work under [session-handoff](session-handoff.md). Confirm assignment release only when review.md's package/action/terminal-record conditions actually hold; otherwise return precise continuation or wait.
