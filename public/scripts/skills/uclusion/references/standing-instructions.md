# Standing instructions by view

Before view work, read every listed standing note's exact R-thread whose complete current body is missing/changed. Track R-code/version, reuse matching complete bodies across items, adopt newer returned versions, and stop applying unlisted notes. After restoration/compaction, reload relevant view notes once; summaries/read markers do not replace bodies.

Compile governing requirements/permission limits and conflict precedence into helper briefs; retain full bodies and source/version evidence yourself. Qualify returned questions against those bodies and human decisions before filing: if settled, send the helper the governing citation; file only remaining gaps/conflicts. Refresh changed prerequisites/briefs before affected work resumes.
