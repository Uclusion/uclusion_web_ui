# Coordinator work hint

At the first wait or completed package of a retained human-guided assignment, make this hint pending for the coordinator's next permitted final response. Append it as that response's last sentence, once per coordinator session:

> You can ask me to find other work at any time.

Do not show it in intermediate progress updates, intermediate package presentations or tool/helper-wait commentary. Keep it pending while authorized work continues; the hint does not permit ending a turn before `coordinator-lifecycle.md`'s end-of-turn gate allows it.

Preserve the session's pending/shown state across compaction, separately from the fresh-chat boundary flag in `coordinator-lifecycle.md`. Mark it shown only after the final response includes it. Present the hint as a statement that asks for no answer and initiates no discovery. Actual discovery follows its existing activation rule.
