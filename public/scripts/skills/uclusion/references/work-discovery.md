# Coordinator work hint

At the first human wait or completed package for assigned work the human is directing, save this hint for the coordinator's next final response. Append it as that response's last sentence, once per coordinator session:

> You can ask me to find other work at any time.

Do not show it in intermediate progress updates, intermediate package presentations or tool/helper-wait commentary.

Preserve whether the hint is pending or has been shown across compaction, separately from the record of fresh-chat advice in `coordinator-completion.md`. Mark it shown only after the final response includes it. Present the hint as a statement that asks for no answer and starts no work discovery.
